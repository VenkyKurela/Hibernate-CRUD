Student Entity CRUD Operations using Hibernate and Oracle Database
 
This project demonstrates CRUD operations on a Student entity using Hibernate and Oracle.
 
Configuration
Database connection details are specified in `hibernate.cfg.xml`. Replace placeholders with your actual Oracle database connection details.
 
Usage
1. Clone the repository.
2. Configure `hibernate.cfg.xml`.
3. Build and run the project.
